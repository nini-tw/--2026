# 🇰🇷 Busan 6 Days Travel App — 2026/10/1–10/6

這是私人旅行行程 Web App，可直接用 GitHub Pages 發布。

## 檔案
- `index.html`：App 主頁
- `lotte-world-map.jpg`：使用者提供的樂天世界釜山園區地圖

## GitHub Pages
1. 建立 GitHub Repository，例如 `busan-trip-2026`。
2. 將 `index.html`、`lotte-world-map.jpg`、`README.md` 放在 Repository 最外層。
3. 進入 `Settings` → `Pages`。
4. `Build and deployment` → `Source` 選 `Deploy from a branch`。
5. `Branch` 選 `main`，資料夾選 `/(root)` → `Save`。
6. 等待部署完成後，按 `Visit site` 即可取得分享網址。

- 本版已依 2026/9/28 查核可取得的官方／公開資料修正部分景點營業時間與交通資訊。
